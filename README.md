# IRONLOG — אפליקציית כושר ותזונה אישית

PWA בעברית (RTL), מצב כהה OLED, עובדת **לגמרי אופליין**. אין build step — הדפדפן טוען בדיוק את מה שיש בתיקייה.

**גרסה 2:** שאלון פתיחה שבונה תוכנית אישית, התאמה אוטומטית לציוד ולמגבלות, ספריית תרגילים, מדידות גוף, מסך סיכום אימון, גרפי התקדמות וסנכרון Google Drive.

---

## העלאה ל-Netlify

**הדרך הכי מהירה (גרירה):**

1. היכנס ל-[app.netlify.com/drop](https://app.netlify.com/drop)
2. גרור את **תוכן** התיקייה (לא את ה-ZIP עצמו — פתח אותו קודם)
3. זהו. תקבל כתובת. פתח אותה בטלפון → תפריט ⋮ → "התקן אפליקציה"

**דרך Git:** חבר את התיקייה ל-repo, ב-Netlify בחר `Publish directory = .` וללא build command. קובץ `netlify.toml` כבר מגדיר את הכל.

> חשוב: PWA דורש HTTPS. Netlify נותן את זה אוטומטית. פתיחה של `index.html` כקובץ מקומי (`file://`) לא תפעיל את ה-service worker.

## תמונות

**84 תרגילים × 2 פריימים** (תנוחת פתיחה ותנוחת סיום), מוצגים בלופ מתחלף במסך האימון — כמו GIF, אבל בלי המשקל שלו.

- **מקור:** [free-exercise-db](https://github.com/yuhonas/free-exercise-db) — רישיון Unlicense (נחלת הכלל), מותר לשימוש מסחרי וללא ייחוס.
- **גודל:** WebP ברוחב 420px, ~11KB לתמונה, 1.9MB לכל הסט.
- **אופליין:** ה-service worker מושך את כל התמונות ברקע אחרי ההתקנה, בקבוצות של 8. הטעינה הראשונה לא מחכה להן.
- **מפת שרירים:** ציור SVG מקורי (`anatomy.js`) — גוף קדמי ואחורי, שריר מוביל בכתום מלא ושרירי עזר בכתום עמום. לא תמונה, לא ספרייה חיצונית.

להוספת תרגילים או החלפת תמונות: ערוך את `MAP` ב-`tools/build-images.py` והרץ אותו מחדש — הוא כותב גם את `js/ex-images.js` וגם את `img/ex/index.json`.

## מפתח Claude API (אופציונלי)

הגדרות → "מאמן AI וניתוח תזונה". המפתח נשמר **רק** ב-IndexedDB של המכשיר ואינו נכלל בקובץ הגיבוי. הבקשות נשלחות ישירות מהדפדפן ל-`api.anthropic.com`.

> שים לב: מפתח שנשמר בדפדפן חשוף לכל מי שיש לו גישה פיזית למכשיר. אל תשתמש במפתח ארגוני.

## התאמה אישית

השאלון בפתיחה (8 שלבים) שומר גיל, גובה, משקל, ניסיון, מטרה, ימי אימון, ציוד ומגבלות. שני האחרונים הם לא קישוט:

- **ציוד** — אם אין לך מכונות, `resolveExercise()` מחליף כל תרגיל מכונה בחלופה עם אותו דפוס תנועה מהציוד שיש לך. אם החלופה כבר נמצאת באימון, הסלוט נמחק במקום לשכפל תרגיל.
- **מגבלות** — ברך/כתף/גב/שורש יד חוסמים רשימת תרגילים מוגדרת (`LIMIT_BLOCKS`) ומפעילים את אותו מנגנון החלפה. אלה ברירות מחדל לתכנון, לא ייעוץ רפואי — כל תרגיל חסום עדיין זמין ידנית מהספרייה.
- **ניסיון** — מתחיל מקבל סט אחד פחות לתרגיל, מתקדם סט אחד יותר.

מסך התוכנית מציג את האימון **אחרי** ההתאמה, עם תג "הותאם" על כל תרגיל שהוחלף.

## סנכרון Google Drive

התחברות עם Google שומרת את הגיבוי ב-`appDataFolder` — תיקייה פרטית של האפליקציה ב-Drive שלך, לא גלויה בקבצים ולא נגישה לאף אפליקציה אחרת. אין שרת באמצע.

דורש Client ID משלך מ-Google Cloud Console; ההוראות המלאות נמצאות בתוך האפליקציה (הגדרות → "איך משיגים?"). ההרשאה המבוקשת היא `drive.appdata` בלבד.

## מנוע העומס הפרוגרסיבי

בכל תחילת אימון המערכת בודקת את הביצוע הקודם של כל תרגיל:

| מצב | פעולה |
|---|---|
| כל הסטים סגרו את ראש הטווח | **עלייה** 2.5% (מורכב) / 5% (בידוד), מעוגל לקפיצה אפשרית בפועל |
| רוב הסטים מתחת לתחתית הטווח | **הורדה** ל-90% לשיקום טכניקה |
| באמצע | אותו משקל, חזרה אחת יותר |

העיגול מתחשב בפלטות שקיימות אצלך בחדר הכושר (הגדרות → פלטות זמינות).
